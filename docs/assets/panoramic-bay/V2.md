# V2 — live Blender revision

Edited in the user's running Blender via MCP. The original source file remains intact; its collection is also retained, hidden, inside `panoramic-bay-v2.blend` as `Original Bay V1 (comparison)`. The active version is `Panoramic Bay V2`.

The new cross-section slopes outward at the bottom, stays vertical in the middle, then slopes inward toward the roof. In application X/Y coordinates, the right-hand frame centerline is `(1.65, 0.10) → (2.05, 0.85) → (2.05, 2.40) → (1.65, 3.20)`, mirrored on the left. Floor width is 3.4 m; middle frame centerline width 4.1 m; roof width 3.3 m. These are design dimensions, not certified collision clearances. The lower slopes, frames and gaskets reduce the usable envelope.

All six lateral facets and two skylights are glazed. Amber lamps are on the flat ceiling only. Cyan floor guides and exterior support rails remain. V2 glass uses blended transparency for a clean material-preview view, with a separate material preserving V1.

- Editable source: `panoramic-bay-v2.blend` in this folder.
- Export: `src/dev/assets/05-panoramic-bay-v2.glb` from repository root.
- Reproducible stages: `scripts/assets/revise-panoramic-bay-live.py`, invoked in Blender with `runpy.run_path(..., init_globals={'STAGE': 'structure'})`, then `glazing`, then `save`. Start with the editable V1 file. Structure stage refuses to duplicate an existing V2.
- Export contains evaluated copies batched by assembly/material; the editable source objects are not joined. Temporary export objects are removed after export.
- Export: 17 meshes, 9 materials, 8,304 triangles, 461,380 bytes (~451 KiB), no textures, animations, cameras or lights.
- Overall exported bounds: approximately 4.82 × 3.54 × 2.033 m, including exterior rails and floor thickness. Floor surface is approximately Y=0; underside Y=-0.27, upper frame Y=3.27.

Visually inspected in the live Blender viewport. Actual GLB parsed with Three.js; checked finite vertices, bounds and geometry counts. The development preview now uses the same V2 runtime URL as `PanoramicPassage`, shared through `PANORAMIC_BAY_ASSET` in `passageLayout.ts`, so it no longer displays V1 for the bay.

## Runtime integration

`PanoramicPassage.tsx` replaces the procedural passage with three cached GLTF instances at native scale, centered at Z=6.116667, 8.15 and 10.183333.
